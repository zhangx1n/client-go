# client-go 小白学习指南

> 你的 Kubernetes 编程教练，从零开始，手把手带你读懂 client-go 源码。

---

## 你在学什么？

client-go 是 Kubernetes 官方 Go 客户端库。kubectl、所有内置控制器、你写的 Operator —— 底层都是 client-go。学会它，你就掌握了 K8s 编程的核心能力。

## 每篇文档包含什么

- **概念讲解** —— 用大白话解释"这是什么"和"为什么需要它"
- **源码导读** —— 精确到文件和行号，告诉你看哪里、看什么
- **核心数据结构** —— 列出关键的 struct 和 interface
- **代码示例** —— 结合 `examples/` 目录中的官方示例
- **小白问答** —— 预判你可能的困惑，提前解答
- **检查清单** —— 每篇结尾有自测问题，确认你真的理解了

## 阅读建议

1. **不要跳着看** —— 后面的内容依赖前面的概念
2. **边看文档边看源码** —— 文档给了精确行号，对照着读
3. **先理解接口，再看实现** —— Go 的接口是理解架构的钥匙
4. **跑一下示例** —— 用 kind/minikube 本地集群运行 `examples/` 中的代码
5. **回答检查问题** —— 如果答不上来，回去重读对应章节
